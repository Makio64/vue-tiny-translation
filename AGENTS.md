# AGENTS.md

Guidance for AI coding agents working in this repo.

## What this is
`vue-tiny-translation` is a minimalist reactive i18n plugin for Vue 3. The entire runtime lives in a single file: [src/index.js](src/index.js) (~1 KB source, ~0.35 KB gzipped). **Small size is a core feature** — prefer not adding code, and never add runtime dependencies.

## Layout
- [src/index.js](src/index.js) — the plugin (only runtime file)
- [src/index.d.ts](src/index.d.ts) — public TypeScript types; keep in sync with the source
- [src/index.test.js](src/index.test.js) — vitest suite; update alongside any API change
- [example/](example/) — standalone Vue 3 + Vite + Three.js demo app
- [dist/](dist/) — rollup build output; **do not hand-edit**
- [rollup.config.js](rollup.config.js), [package.json](package.json), [CHANGELOG.md](CHANGELOG.md), [PUBLISHING.md](PUBLISHING.md)

## Commands
Package manager is **pnpm** (see `packageManager` in [package.json](package.json)).

```bash
pnpm install          # install deps
pnpm test             # run vitest once
pnpm build            # rollup + copy .d.ts into dist/
pnpm dev              # rollup watch
```

Example app (uses npm per its own README):
```bash
cd example && npm install && npm run dev
```

## Public API
Exported from [src/index.js](src/index.js) and typed in [src/index.d.ts](src/index.d.ts):

- `translate(key, defaultValue?)` — named export; resolves dot-path keys against the current dictionary
- `setTranslations(dict)` — replace the full translation map
- `loadTranslations(url)` — fetch JSON from a URL and call `setTranslations`
- `useTranslation()` — composable returning `{ t, loadTranslations, setTranslations }`
- default export — a Vue plugin that registers `$t` globally via `app.config.globalProperties.$t`

Translations are stored in a `reactive` object, so language switches propagate without reload.

## Conventions
- Keep the source **tiny**. A three-line addition that bloats the gzipped size is a regression.
- Any behavior change must come with a matching test in [src/index.test.js](src/index.test.js).
- Update [CHANGELOG.md](CHANGELOG.md) on release (see [PUBLISHING.md](PUBLISHING.md) for the flow).
- Do not break the existing signatures in [src/index.d.ts](src/index.d.ts) without a major version bump.

## Don't
- Don't add runtime dependencies (Vue is a peer dep, nothing else).
- Don't edit files in [dist/](dist/) — they are regenerated by `pnpm build`.
- Don't introduce framework coupling beyond Vue 3 (`reactive`, `getCurrentInstance`).
- Don't add build tooling to the example app that the demo doesn't actually need.
